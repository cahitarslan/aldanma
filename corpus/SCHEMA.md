# Corpus format

`corpus.json` is `{ "description": "...", "messages": [ ... ] }`. `tools/evaluate.mjs` also accepts a bare array.

| Field | Required | Values |
|---|---|---|
| `id` | no | unique string, e.g. `D001` (scam) / `M001` (genuine) |
| `label` | yes | `scam` or `legit` |
| `text` | yes | message text as received |
| `sender` | no | `unknown` (default), `header` (company name or short code), `mobile` (05xx), `foreign`, `whatsapp` |
| `category` | no | expected category id from `rules/rules.json` (scams), or a free topic for genuine messages |
| `split` | no | `train`, `holdout`, `hard`, `blind1`, `blind2`, or your own |

Rules for new messages: no real names, phone numbers, IBANs or ID numbers; invented domains only (never `example.com`, which the
tests reject). Do not add a message to a split the rules were already tuned on and then call the result blind.

`parity-extra.json` holds edge-case inputs used only by the C#/JS parity check. `expected-js.json` is generated by `npm run parity`.
